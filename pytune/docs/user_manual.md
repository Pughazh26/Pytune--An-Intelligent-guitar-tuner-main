# User Manual

## 1. Guitar Tuner

1. Navigate to the **Tuner** page.
2. Click **Start Tuning**.
3. Allow microphone permission when prompted.
4. Pluck a single guitar string clearly.
5. The meter will show if you are **Sharp** (Right, Yellow) or **Flat** (Left, Red).
6. Tune your guitar until the meter is centered and green (**In-Tune**).

**Supported Strings**: Standard Tuning (E2, A2, D3, G3, B3, e4).

## 2. AI Music Generator

1. Navigate to the **AI Music** page.
2. Select a **Genre** (e.g., Lo-fi, Pop).
3. Adjust **Tempo** and **Mood**.
4. Set the **Duration** (up to 60s).
5. Click **Generate Music**.
6. Wait for the AI to compose.
7. Listen to the track or download the **WAV/MIDI** files.

View your usage statistics, most played genres, and tuning accuracy over time.
